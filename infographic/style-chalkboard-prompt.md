# Chalkboard Infographic Style Prompt

Prefix this to all chalkboard-style infographic prompts for visual consistency.

## Reference Image

`infographic/5-levels-ai-coding/style-chalkboard.png`

## Style Prompt Prefix

```
Hand-drawn chalk illustration on a dark black chalkboard with subtle grey chalk dust texture in the background. White chalk outlines for all structural graphics and diagrams. Title in large hand-drawn white chalk lettering. Body text in clean white chalk. Key details and small illustrative sketches highlighted with colored chalk accents (yellow, green, blue, orange, pink). No wooden frame or border. Style should look like a teacher's blackboard drawing — organic, slightly imperfect linework, educational feel. Dark matte black background, not green.
```

## Style Notes

- **Background**: Dark charcoal/black chalkboard with subtle dusty wiped-chalk residue (grey smudges/noise). NOT green.
- **Title**: Large hand-drawn chalk lettering — slightly irregular, white
- **Graphics**: White chalk outlines for structural elements. Clean line-drawn style, not filled shapes
- **Illustrations**: Small colored chalk sketches alongside the main structure — each concept gets a different chalk color
- **Text body**: White chalk for main labels and descriptions
- **Color accents**: Sparingly used for icons/illustrations and key emphasis, not for large areas
- **No frame**: No wooden frame or border
- **Feel**: Like a teacher drew this on a real blackboard during a lecture
